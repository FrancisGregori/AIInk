🎨 Proceso de Generación de Imagen
Backend recibe la petición:

// Construye el contenido para Gemini
contents = [
  {
    inlineData: {
      data: imageBase64,      // La imagen original
      mimeType: mimeType,     // "image/jpeg", "image/png", etc.
    },
  },
  prompt,                   // "Cambia el fondo a azul"
];
// Envía a Gemini 2.5 Flash Image Preview
const response = await ai.models.generateContent({
  model: "gemini-2.5-flash-image-preview",
  contents: contents,
});
Gemini procesa y devuelve:

// Extrae la imagen editada de la respuesta
for (const part of content.parts) {
  if (part.inlineData && part.inlineData.data) {
    return {
      mimeType: "image/png",               // Siempre PNG
      dataBase64: part.inlineData.data     // Imagen editada en base64
    };
  }
}
🔄 Magia de la Edición Continua
Cuando llega la imagen editada:

onSuccess: async (data) => {
  // 1. Muestra la imagen editada en el chat
  setMessages(prev => [...prev, {
    content: "He editado tu imagen. Puedes seguir editándola:",
    editedImage: {
      dataBase64: data.dataBase64,
      mimeType: data.mimeType
    }
  }]);
  // 2. CLAVE: Convierte la imagen editada en la nueva imagen cargada
  const editedFile = await base64ToFile(data.dataBase64, "edited-image.png");
  const editedPreview = URL.createObjectURL(editedFile);
  
  setUploadedImage({
    file: editedFile,
    preview: editedPreview,
    base64: data.dataBase64     // ¡Esta es ahora la imagen base!
  });
}
