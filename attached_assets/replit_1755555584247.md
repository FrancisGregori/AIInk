# TattoostencilPro

## Overview
TattoostencilPro is a web application designed for tattoo artists to convert images into stencil designs. It enables users to upload images, choose from various stencil styles, customize processing options, and download the final stencil artwork. The application features a modern React frontend and an Express.js backend, built for real-time processing, job status tracking, and a gallery display of completed work. The project aims to provide a professional tool for tattoo artists, leveraging AI models trained on specific artist styles to produce high-quality stencil designs.

## User Preferences
Preferred communication style: Simple, everyday language in Spanish.
Design aesthetic: Minimalist black interface with only black, gray (zinc tones), and white colors. No blue or green accent colors.
Branding: Logo displays "TattoostencilPro" with "By Darwin Enriquez" credit below.

## System Architecture

### Frontend
- **Framework**: React 18 with TypeScript and Vite.
- **UI**: shadcn/ui components based on Radix UI and Tailwind CSS.
- **State Management**: TanStack Query for server state and caching.
- **Routing**: Wouter.
- **File Upload**: react-dropzone.
- **Form Handling**: React Hook Form with Zod validation.

### Backend
- **Runtime**: Node.js with Express.js.
- **Language**: TypeScript with ES modules.
- **File Handling**: Multer for multipart uploads.
- **API**: RESTful, JSON responses, comprehensive error handling.

### Data Storage & Database
- **Database**: PostgreSQL with Drizzle ORM, hosted on Supabase Database with Row Level Security (RLS).
- **Schema Management**: Drizzle Kit for migrations.
- **Object Storage**: Supabase Storage with RLS-enabled buckets:
  - "uploads" bucket: Private storage for original images, organized by user_id folders
  - "renders" bucket: Private storage for processed stencils, organized by user_id folders
  - Both buckets use signed URLs with 7-day expiry for secure access
- **Schema**: User profiles (linked to Supabase Auth, with subscription/usage tracking), and Stencil Jobs (tracking image processing, URLs, styles, status, ComfyDeploy run ID, user association).
- **Job Status Flow**: pending → processing → completed/failed.
- **Privacy**: Each user's images are completely private - gallery shows empty for public access, only authenticated users see their own images.
- **Migration Complete (August 10, 2025)**: Successfully migrated from Replit Object Storage to Supabase Storage with full RLS support and user privacy.

### Authentication
- Supabase Auth for user management (email/password, Google OAuth) and JWT token validation.
- Session refresh logic to handle token expiration automatically.
- Token verification using Supabase client with anon key for proper validation.
- Google OAuth configured and enabled (August 11, 2025).
- Email confirmation disabled for faster development access.
- Google OAuth opens in new window to avoid iframe restrictions in Replit environment (January 10, 2025).
- Authentication interface fully translated to Spanish for better user experience.

### File Management & Processing
- **Uploads**: Direct to Supabase Storage using presigned URLs (future goal), currently via Replit Object Storage for originals.
- **Validation**: Image types (JPEG, PNG, GIF) and size limit (10MB).
- **Processing Options**: Multiple stencil styles (Steven, Makishi, Darwin, Adrian) mapped to ComfyDeploy LoRA models, transparent background toggle, quality adjustment (50-100%).

### API Endpoints
- `POST /api/objects/upload`: Get presigned URL.
- `POST /api/stencils`: Create processing job.
- `GET /api/stencils/:id`: Retrieve job status/results.
- `GET /api/gallery`: Fetch latest completed stencils.
- `GET /objects/:path`: Serve images from object storage.

### Real-time Features
- Polling (2-second interval) for job status updates from ComfyDeploy.
- Comprehensive error handling and user feedback.
- Auto-scroll to style selection after image upload.
- Simplified download section with manual copy instructions for Procreate (January 16, 2025) - Removed problematic clipboard API implementation due to iOS/Safari limitations.

### Development Tools
- **Build System**: Vite with React plugin for HMR.
- **Type Checking**: TypeScript across all layers.
- **Path Mapping**: `@` aliases for organized imports.
