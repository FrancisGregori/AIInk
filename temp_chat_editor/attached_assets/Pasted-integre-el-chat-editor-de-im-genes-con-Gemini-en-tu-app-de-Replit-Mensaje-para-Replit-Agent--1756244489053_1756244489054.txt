📩 Mensaje para Replit Agent (copiar/pegar)

Quiero agregar dos endpoints con Gemini:

1) Chat (texto → texto)

Endpoint: POST /api/chat

Modelo: gemini-2.5-flash

Body: { "messages": [{ "role":"user", "content":"texto..." }] }

Respuesta: { "text": "..." }

Reintentos y manejo de errores estándar.

2) Edición de imágenes (texto + imagen → imagen)

Endpoint: POST /api/edit-image

Modelo: gemini-2.5-flash-image-preview

Acepta dos modos:

inline: { "prompt":"...", "imageBase64":"...", "mimeType":"image/jpeg|png|webp|heic|heif" }

files API: { "prompt":"...", "fileUri":"..." } (subida previa y reuso por 48h)

Respuesta: { "mimeType":"image/png", "dataBase64":"<imagen>" }

Validar tamaño/MIME, y devolver 400 si no cumple.

Infra & librerías

Añadir secreto GEMINI_API_KEY en Secrets de Replit y usarlo en el servidor (process.env.GEMINI_API_KEY).

Instalar SDK oficial: npm i @google/genai y crear un cliente único para todo el server.

Servidor Node/Express (TypeScript si es posible) con express.json({ limit: "25mb" }).

Aceptación (checklist)

 POST /api/chat responde en <2s con texto del modelo gemini-2.5-flash.

 POST /api/edit-image devuelve imagen editada (base64) usando gemini-2.5-flash-image-preview.

 Soporta multi-imagen (varias inlineData o varios fileUri).

 Manejo de errores con códigos 4xx/5xx y mensajes claros.

 Variables en Replit Secrets (no .env), y Deploy creado con los mismos secrets.

 Incluir 2 scripts de prueba (curl) en README.md.

Extras opcionales

Helper para subir a Files API (resumable) y devolver fileUri.

Logger básico y CORS habilitado para mi frontend.

Endpoint de salud GET /healthz.

🧪 cURL de prueba (añade al README)

Chat

curl -s -X POST https://TU_APP.replit.app/api/chat \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"Dime en 5 palabras qué es un stencil"}]}'


Edición de imagen (inline base64)

IMG="ruta/a/tu.jpg"; B64=$(base64 -w0 "$IMG" 2>/dev/null || base64 "$IMG")
curl -s -X POST https://TU_APP.replit.app/api/edit-image \
  -H "Content-Type: application/json" \
  -d '{
    "prompt":"Replace the background with a clean white studio backdrop; keep tattoo linework unchanged",
    "mimeType":"image/jpeg",
    "imageBase64":"'"$B64"'"
  }' | jq -r .dataBase64 | base64 --decode > edited.png
