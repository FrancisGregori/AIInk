      prompt: message,

🔄 Flujo de Funcionamiento
Subir imagen: Usuario arrastra/selecciona imagen → Se convierte a base64 → Aparece como miniatura
Escribir instrucción: Usuario escribe cómo quiere editar la imagen
Procesar: Frontend envía prompt + imagen al backend
Gemini AI: Backend usa Gemini 2.5 Flash Image Preview para editar
Mostrar resultado: Imagen editada regresa como base64 → Se muestra en el chat
Continuar editando: La imagen editada se convierte en la nueva imagen base
🛠️ Tecnologías Clave
React Query: Manejo de peticiones HTTP y cache
Google Gemini API: IA para chat (gemini-2.5-flash) y edición de imágenes (gemini-2.5-flash-image-preview)
Tailwind CSS: Estilos responsivos y tema claro/oscuro
TypeScript: Tipado estático para mayor seguridad
Express.js: Servidor web con middleware para archivos grandes (25MB)
💡 Características Especiales
Edición continua: La imagen editada se mantiene cargada para seguir editándola
Miniatura inteligente: Muestra preview compacto junto al input
Respuestas concisas: Gemini configurado para dar respuestas cortas (máx 150 tokens)
Manejo de errores: Validación de tipos de archivo y tamaños
