Para que cada usuario tenga una experiencia coherente y privada, el flujo ideal de la aplicación debería ser:

Generación de imágenes (Stencil Tool y Design Editor)

Cada vez que el usuario genera o modifica una imagen, la vista correspondiente envía una petición POST /api/gallery con la información del diseño (URL, tipo, título) asociada al ID del usuario autenticado.

Si el diseño corresponde a un proyecto Flux, se registra también en el listado de proyectos personales del usuario.

El componente (Stencil o Design Editor) añade inmediatamente esa imagen al historial local para que el usuario la vea sin recargar.

Persistencia en el servidor

El servidor guarda la información en un almacenamiento duradero (BD o archivo), no en memoria, de modo que las imágenes siguen disponibles tras reinicios.

Cada entrada se marca con el ID del usuario, de modo que sólo él puede consultarla.

Galería unificada

La página “Mi Galería” realiza una petición autenticada GET /api/gallery (con paginación/carga incremental) para obtener todos los ítems del usuario.

Las imágenes guardadas desde ambos módulos (Stencil y Design Editor) aparecen aquí, sin límites rígidos de 15 elementos.

Historial dentro de cada herramienta

Al abrir Stencil o Design Editor, el cliente recupera los diseños previos del usuario (guardados en la galería o en proyectos Flux) y muestra las miniaturas, iniciando el listado desde el primer elemento generado.

Las imágenes completadas o fallidas se conservan en localStorage como respaldo, y se sincronizan al cargar la página.
